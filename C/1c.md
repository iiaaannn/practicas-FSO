# Introducción al lenguaje C

Ejemplo de programa en C :

```c
#include <stdio.h>

int main() {
    printf("Hola mundo");
}
```

***<stdio.h>*** $\rightarrow{}$ fichero de <u>cabecera</u>. Proporciona declaraciones de funciones, variables y constantes sin incluir sus definiciones completas.

Todas las instrucciones en C acaban por ";".

## Comentarios

Dos formas : 

```c
// una linea
/*
varias 
lineas
*/
```

## Palabras reservadas en C

| | | | |
| :---: | :---: | :---: | :---: |
| `auto` | `break` | `case` | `char` |
| `const` | `continue` | `default` | `do` |
| `double` | `else` | `enum` | `extern` |
| `float` | `for` | `goto` | `if` |
| `int` | `long` | `register` | `return` |
| `short` | `signed` | `sizeof` | `static` |
| `struct` | `switch` | `typedef` | `union` |
| `unsigned` | `void` | `volatile` | `while` |

**char** $\rightarrow$ 1 byte  
**unsigned char** $\rightarrow$ 1 byte  
**short** $\rightarrow$ 2 bytes  
**unsigned short** $\rightarrow$ 2 bytes  
**int** $\rightarrow$ 4 bytes  
**unsigned int** $\rightarrow$ 4 bytes  
**long** $\rightarrow$ 8 bytes (en sistemas de 32 bits)  
**unsigned long** $\rightarrow$ 8 bytes (en sistemas de 32 bits)

Para poder usar valores <u>booleanos</u> (True/False) debemos importar el fichero de cabecera ***<stdbool.h>***

```c
#include <stdbool.h>
```

## Asignación de variables

```c
#define PI 3.14 // variable global

int main() {
    int entero1, entero2;
    char c1;
    float real1, real2;
    double d1;
    // variables locales
}
```

## Operaciones aritméticas

* **suma** : `a + b;`
* **resta** : `a - b;`
* **incremento** : `a++;`
* **decremento** : `a--;`
* **multiplicación** : `a*b;`
* **división** : `a / b;`
* **módulo/resto** : `a % 2;`

> [!IMPORTANT]
> No es lo mismo hacer `++a` que `a++`, y lo mismo con `--a` y `a--`

## Operaciones lógicas y comparación

### Operaciones lógicas

* **AND** : `j && k`
* **OR** : `j || k`
* **Negación** : `!j`

### Comparación

* **mayor** : `j > k`
* **mayor o igual** : `j >= k`
* **menor** : `j < k`
* **menor o igual** : `j <= k`
* **igual** : `j == k`
* **distinto** : `j != k`
