# Introducción al lenguaje C

Ejemplo de programa en C :

```c
#include <stdio.h>

int main() {
    printf("Hola mundo");
}
```

***<stdio.h>*** $\rightarrow{}$ fichero de <u>cabecera</u>. Proporciona declaraciones de funciones, variables y constantes sin incluir sus definiciones completas.

Todas las instrucciones en C acaban por ";".

## Operaciones aritméticas

* **suma** : `a + b;`
* **resta** : `a - b;`
* **incremento** : `a++;`
* **decremento** : `a--;`
* **multiplicación** : `a*b;`
* **división** : `a / b;`
* **módulo/resto** : `a % 2;`

> [!IMPORTANT]
> No es lo mismo hacer `++a` que `a++`, y lo mismo con `--a` y `a--`

## Operaciones lógicas y comparación

### Operaciones lógicas

* **AND** : `j && k`
* **OR** : `j || k`
* **Negación** : `!j`

## Estructuras condicionales

### If

```c
if (condicion) {
    // Codigo a ejecutar si se cumple "condicion"
}
```

- Si la condición es un <u>**entero**</u>, se considera verdadera la condición si el entero es distinto de 0, y falso si es 0.

```c
int valor = 4;
if (valor) { ... }
```

- Si la condición es un valor <u>**lógico**</u>, la expresión se evalúa directamente como verdadera (true) o falsa (false).

```c
bool condicion = true;
if (condicion) { ... }
```

- Si la condición es un <u>**real**</u>, se considera verdadera si es distinto de 0.0 y falsa si es 0.0.

```c
double condicion = 0.4;
if (condicion) { ... }
```

> [!Note]
> Hay que tener cuidado en no confundir '=' y '==' 

### If-Else

```c
if (condicion) {
    // codigo a ejecutar si la condicion es verdadera
} else {
    // codigo a ejecutar si la condicion es falsa
}
```

### Switch

```c
int opcion = 2;
switch (opcion) {
    case 1:
        printf("Opcion 1 seleccionada\n");
    case 2:
        printf("Opcion 2 seleccionada\n");
    default:
        printf("No coincide ni con opcion 1 ni con opcion 2\n");
}
```

> [!Note]
> El switch debe ser de tipo <u>entero</u> (int, char...)

## Ciclo de vida de las variables

La vida de una variable está limitada por el bloque de código donde se inicializa :

```c
int main() {
    int j = 2;
    for (int i = 0; i < 10; i++) {
        j = j + 2;
    }

    j = 5; // correcto
    i = 6; // ERROR : i ya no existe
}
```

```c
int var; // variable GLOBAL (accesible desde todo el codigo)

int main() {
    ...
}
```

> [!Note]
> Una variable <u>local</u> (definida dentro de una funcion o un bloque { }) tiene más prioridad que una variable <u>global</u>

## Entrada y salida

```c
int printf("<cadena control>" [, <argumentos>]);
```

`printf()` imprime texto formateado por terminal. La cadena de texto especifica el formato y determina el numero de argumentos mediante los <u>**descriptores de formato (%?)**</u> (los argumentos deben ir separados por comas)

| Especificador | Descripción |
| :--- | :--- |
| `%c` | Carácter sencillo |
| `%d`, `%i` | Entero |
| `%ld` | Long |
| `%e` | Real en notación científica |
| `%f` | Float |
| `%lf` | Double |
| `%g` | El más corto de `%e` y `%f` |
| `%o` | Número octal |
| `%x` | Número hexadecimal |
| `%s` | Cadena de caracteres |
| `%u` | Decimal sin signo |
| `%p` | Puntero o dirección de memoria |

> [!Note]
> m.n controlan la anchura total y la precisión al imprimir un valor. m es el <u>nº mínimo de caracteres</u> que ocupa el valor por pantalla, y n la <u>precisión</u>. Para los **floats** (f), indica el número de dígitos decimales a mostrar. Para **cadenas** (s), el número máximo de caracteres que se mostrarán. Y para **enteros** (d), el mínimo número de dígitos a mostrar (rellenando con 0's a la izquierda si hace falta)

```c
int scanf("<cadena control>" [, <argumentos>]);
```

`scanf()` lee de teclado. La cadena de control es igual que printf(). Devuelve el número de argumentos leídos correctamente. Los argumentos son las variables o expresiones a leer. Por cada descriptor de formato (%?) en la cadena de control, debe haber un argumento, que deben ser tipos escalares (int, float, double, char), y deben llevar delante el operador de <u>**dirección** (&)</u>

> [!Note]
> Para poder usar las funciones printf() y scanf() es necesario importar el archivo de cabecera <stdio.h>

> [!Note]
> scanf() no puede leer líneas enteras con espacios en blanco. Para eso usamos <u>fgets</u>

`scanf()` devuelve un valor entero que indica el número de datos que se han podido leer correctamente. Si `scanf()` encuentra un error o no puede leer los datos correctamente, entonces devuelve un número menor al número de variables proporcionadas en la llamada :

```c
int main() {
    int num1, num2;
    printf("Introduce dos números : ");

    if (scanf("%d %d", &num1, &num2) == 2) { // datos leídos correctamente
        printf("num1 : %d\nnum2 : %d\n", num1, num2);
    } else {
        printf("Error en la entrada\n");
    }
    return 0;
}
```

Para imprimir código de color por terminal : 

```c
int main() {
    printf (" \033[1;31 mEste texto es rojo .\033[0 m\n") ;
    printf (" \033[1;32 mEste texto es verde .\033[0 m\n");
    printf (" \033[1;34 mEste texto es azul .\033[0 m\n") ;
    printf (" \033[1;33 mEste texto es amarillo .\033[0 m\n");
    printf (" \033[1;35 mEste texto es magenta .\033[0 m\n");
    printf (" \033[1;36 mEste texto es cian .\033[0 m\n") ;
    printf (" Este texto es normal .\n");
    return 0;
}
```

> [!Note]
> El código `\033[0m` se utiliza para restablecer el color de la terminal después de usar otro color. Si no lo ponemos, todos los textos de después seguirán en ese color y no en el de la terminal.

## Funciones

Se declaran precedidas del tipo de dato que devuelven. Los parámetros también se declaran precedidos de su tipo y uno a uno. Las funciones se declaran <u>antes</u> del main, y la palabra reservada `return` permite retornar el valor de la función.

```c
double suma(double a, double b) {
    return  a + b;
}

void main() {
    double a = 1.6, b = 3.4;
    printf("%f + %f = %f\n", a, b, suma(a,b));
}
```

También podemos declarar funciones sin definir su cuerpo (antes del main), y después del main definir su cuerpo : 

```c
double suma(double a, double b);

void main() {
    double a = 1.6, b = 3.4;
    printf("%f + %f = %f\n", a, b, suma(a,b));
}

double suma(double a, double b) {
    return a + b;
}
```

> [!Note]
> Si una función no devuelve nada (es decir, es un procedimiento/subrutina), usamos la palabra reservada `void`.

> [!Important]
> Cuando pasamos una variable a una función, se pasa una <u>copia</u>, no el valor original. Por lo que aunque creamos que estamos cambiando el valor de una variable, sólo estamos modificando la copia. Entonces si queremos cambiar el valor de la variable, tenemos que pasarle la <u>**dirección de memoria**</u> de la variable.
